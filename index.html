Facturación y consultas

Cisma Fact — Facturación electrónica y API RUC/DNI

Emite comprobantes, consulta datos de personas y empresas, o integra ambos servicios directamente con tu sistema.

  • Facturas, boletas, notas de crédito, débito y guías de remisión.
  • Firma con certificado digital y envío directo a SUNAT.
  • Seguimiento del estado de cada comprobante.
  • Descarga de PDF, XML y respuesta CDR.
  • API REST documentada para integrar tu propio sistema.
  • Consultas de personas por DNI y empresas por RUC.

Demo gratuita

Prueba la facturación y las consultas DNI/RUC

Utiliza la consola para enviar solicitudes de prueba, revisar las respuestas de la API y conocer el flujo antes de integrarlo.

  • Configura la conexión con las credenciales proporcionadas.
  • Envía facturas y boletas de prueba mediante la API.
  • Revisa la respuesta y el PDF generado del comprobante.
  • Consulta un DNI y recibe nombres y apellidos.
  • Consulta un RUC y recibe razón social, estado, condición y domicilio fiscal.
  • Detecta respuestas correctas y errores antes de conectar tu sistema real.
